# Gatling GraphQL - Scala with SBT demo project

This folder contain a SBT project that shows how to use the Gatling GraphQL DSL with Scala.

## Usage

To run the demo simulation, use the `Gatling / testOnly` SBT task:

```console
sbt "Gatling / testOnly io.gatling.graphql.demo.GraphQlDemoSimulation"
```
