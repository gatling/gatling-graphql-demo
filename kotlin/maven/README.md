# Gatling GraphQL - Kotlin with Maven demo project

This folder contain a Maven project that shows how to use the Gatling GraphQL DSL with Kotlin as writing language and Java
generated objects.


## Usage

To run the demo simulation, use the `gatling:test` Maven goal:

```console
mvn gatling:test -Dgatling.simulationClass=io.gatling.graphql.demo.GraphQlDemoSimulation
```
